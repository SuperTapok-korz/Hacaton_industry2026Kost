# Qostanai Proctor — прототип локального прокторинга

Демо для кейса 3 Qostanai Industry Hackathon: локальный просмотр камеры, поиск лица и смартфона, грубая оценка положения взгляда и журнал предупреждений. Видео не записывается и не отправляется на сервер.

## Запуск в Windows

Нужен Python 3.11. В терминале VS Code, открытом в папке проекта:

```powershell
py -3.11 -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe main.py
```

При первом запуске Ultralytics скачает `yolov8n.pt` (нужен интернет). Можно заранее положить эту модель рядом с `main.py`; при последующих стартах сеть не нужна. Выберите веб-камеру Windows по умолчанию.

## Функции прототипа

- MediaPipe Face Mesh показывает лицо и оценивает направление радужки: на экран, вниз, влево или вправо.
- YOLOv8n находит класс `cell phone` из COCO; в кадре выделяется телефон и добавляется предупреждение.
- Отсутствие лица и несколько лиц в кадре фиксируются в журнале.
- Кнопка завершения и закрытие окна освобождают камеру.

## Ограничения демо

Направление взгляда — приблизительная эвристика по положению радужки, без калибровки; это не медицинское или доказательное измерение. COCO-модель находит телефон, но сама по себе не определяет, фотографирует ли человек экран. Журнал существует только в окне и не сохраняется. Защита ОС (Alt+Tab, Win, снимки экрана, другие приложения и вкладки) пока не реализована: надёжная блокировка требует отдельного режима киоска/управляемого браузера Windows и не должна имитироваться глобальными перехватчиками клавиш.

Используйте систему как демонстрационный сигнал для наблюдателя, а не как автоматическое основание для обвинения или оценки студента.
