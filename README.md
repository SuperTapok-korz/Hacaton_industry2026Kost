# Qostanai Proctor — локальный прототип

Демо для кейса 3 Qostanai Industry Hackathon: просмотр камеры, поиск лица и смартфона, приблизительная оценка направления взгляда и журнал предупреждений. Видео анализируется на компьютере и не сохраняется.

## Установка и запуск в Windows

### Если в терминале уже написано `(venv)`

Терминал уже находится в папке проекта и виртуальное окружение включено. Для запуска введи одну команду:

```powershell
python main.py
```

### Первый запуск на новом компьютере

Нужен Python 3.11 (64-разрядный). Скачайте проект из ветки `geras-branch` и откройте его папку в VS Code. В меню VS Code выберите **Терминал → Создать терминал** и выполните:

```powershell
py -3.11 -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip install --force-reinstall --no-cache-dir -r requirements.txt
.\venv\Scripts\python.exe main.py
```

Все библиотеки, включая PyTorch, MediaPipe, Matplotlib и YOLO, перечислены в одном файле — `requirements.txt`. Установка PyTorch настроена на работу через процессор, видеокарта не требуется. Для установки и первого запуска нужен интернет: модель YOLO автоматически загрузится при первом запуске.

Если папка `venv` уже есть, первую команду создания окружения пропустите. Если установка прервалась, запустите команду установки ещё раз.

### Переносимая сборка для Windows

После установки библиотек запусти `build_windows.ps1` из папки проекта. Скрипт при необходимости установит PyInstaller, скачает `yolov8n.pt` (нужен интернет при первой сборке), соберёт приложение и создаст архив `dist\QostanaiProctor.zip`. Передавай команде весь архив; Python и библиотеки на их компьютерах для запуска сборки не нужны. Архив может быть большим из-за PyTorch.

Для киоск-режима Windows 11 Pro подготовлены отдельные файлы и инструкция в папке `kiosk`. Сначала проверь переносимую сборку, затем следуй инструкции для отдельной учётной записи.

## Возможности прототипа

- MediaPipe Face Mesh отмечает лицо. В первые 24 кадра смотрите на экран для калибровки; затем приложение сглаживает движения глаз и головы, показывает небольшой или сильный отвод и записывает только устойчивые отклонения.
- YOLOv8n ищет смартфон, даже если часть закрыта рукой; если он перемещается вверх в кадре, журнал отмечает возможную попытку съёмки.
- Отсутствие лица и несколько лиц отмечаются в журнале.
- После запуска проверки доступен полноэкранный пробный тест с вопросами.
- В полноэкранном демо-тесте приложение пресекает Ctrl+C/Ctrl+V и Esc, отмечает Print Screen, а уход из окна и возврат фиксирует в журнале.
- При обнаружении возможного смартфона сохраняется отдельный снимок кадра с рамкой детекции; снимок записывается в `reports/screenshots`, а путь к нему — в CSV-отчёт.
- Снимок можно открыть двойным щелчком по соответствующему событию в журнале.
- Кнопка **«Снимки сессии…»** показывает галерею всех снимков текущей проверки.
- На видеопотоке и снимках отображается подпись `by.horizon`.
- После завершения проверки журнал автоматически сохраняется в CSV в `reports`. У исходного кода папка находится рядом с `main.py`; у переносимой сборки — `%LOCALAPPDATA%\QostanaiProctor\reports`. Кнопку **«Сохранить копию отчёта…»** можно использовать и во время проверки.
- Кнопка **«Экспорт отчёта и снимков…»** создаёт ZIP с CSV и снимками, чтобы отправить материалы одним файлом. Архив по умолчанию сохраняется в `reports` и не загружается в GitHub.
- Кнопка завершения и закрытие окна освобождают камеру.

## Ограничения

Оценка взгляда приблизительная: калибровка снижает чувствительность к естественным небольшим движениям, но не заменяет специализированный трекер глаз. Обнаружение телефона зависит от видимой части: полностью закрытый рукой телефон камера распознать не сможет. Детектор может ошибаться: снимок показывает кадр и результат модели, но не доказывает нарушение. Подъём телефона — эвристический сигнал по его перемещению и положению; система не распознаёт направление камеры телефона и не может подтвердить, что человек фотографирует экран. Видео не записывается; изображения сохраняются только при срабатывании детектора телефона. Демо-режим фиксирует уход и возврат в окно, но Alt+Tab и клавиша Windows остаются доступны и другие программы не блокируются. Для системного киоск-режима нужно отдельно настраивать Windows. Прототип служит демонстрацией и не должен сам по себе использоваться как доказательство нарушения.
