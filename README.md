# Qostanai Proctor — локальный прототип

Демо для кейса 3 Qostanai Industry Hackathon: просмотр камеры, поиск лица и смартфона, приблизительная оценка направления взгляда и журнал предупреждений. Видео анализируется на компьютере и не сохраняется.

## Установка и запуск в Windows

### Если в терминале уже написано `(venv)`

Терминал уже находится в папке проекта и виртуальное окружение включено. Для запуска введи одну команду:

```powershell
python main.py
```

### Первый запуск на новом компьютере

Нужен Python 3.11 (64-разрядный). Скачайте проект из ветки `geras-branch` и откройте его папку в VS Code. В меню VS Code выберите **Терминал → Создать терминал** и выполните:

```powershell
py -3.11 -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip install --force-reinstall --no-cache-dir -r requirements.txt
.\venv\Scripts\python.exe main.py
```

Все библиотеки, включая PyTorch, MediaPipe, Matplotlib и YOLO, перечислены в одном файле — `requirements.txt`. Установка PyTorch настроена на работу через процессор, видеокарта не требуется. Для установки и первого запуска нужен интернет: модель YOLO автоматически загрузится при первом запуске.

Если папка `venv` уже есть, первую команду создания окружения пропустите. Если установка прервалась, запустите команду установки ещё раз.

### Установка для Windows в один запуск

Готовый файл установки называется `dist\QostanaiProctorSetup.exe`. После запуска он устанавливает программу в профиль текущего пользователя, добавляет ярлыки на рабочий стол и в меню «Пуск», затем запускает приложение. Права администратора не нужны. Для установки интернет не нужен. Установщик занимает около 500 МБ, готовая программа — около 1,5 ГБ; освободите не менее 2 ГБ на диске. Для камеры телефона через USB должны быть установлены и запущены DroidCam Client и его драйвер — установщик проктора их не ставит.

Чтобы собрать установщик из исходного кода, установите зависимости по инструкции выше, затем запустите PowerShell из папки проекта и выполните:

```powershell
.\build_windows.ps1
```

Сборка выполняется на Windows с Python 3.11 и создаёт установщик и переносимую папку в `dist`. Передавайте другим участникам именно файл `QostanaiProctorSetup.exe`; Python, VS Code и отдельная установка библиотек на их компьютерах не нужны.

### Что лежит в папке проекта

- `main.py` — интерфейс и логика приложения: захват камеры, анализ лица и взгляда через MediaPipe, поиск телефона через YOLO, события и снимки, отчёты и демонстрационный тест.
- `requirements.txt` — список Python-библиотек для запуска и сборки из исходников.
- `yolov8n.pt` — готовые веса модели YOLO для поиска объектов, включая телефон.
- `build_windows.ps1` — сборка приложения и установщика Windows.
- `kiosk` — описание ограничений Windows и черновые настройки режима киоска. Файлы из этой папки автоматически не применяются.
- `reports` — локальные CSV-отчёты и снимки сессий; их не нужно отправлять в общий репозиторий.
- `venv`, `build`, `dist` — локальная среда, временные файлы сборки и готовый пакет; это не исходники и они не нужны при передаче кода.

Во время демо-теста программа временно блокирует основные сочетания клавиш. Подробнее об ограничениях защиты Windows см. `kiosk/README.md`.

## Возможности прототипа

- MediaPipe Face Mesh отмечает лицо. В первые 24 кадра смотрите на экран для калибровки; затем приложение сглаживает движения глаз и головы, показывает небольшой или сильный отвод и его длительность. Если отвод сохраняется 2,5 секунды, журнал отдельно фиксирует событие «Длительный отвод взгляда».
- YOLOv8n ищет смартфон с повышенной детализацией; журнал подтверждает находку после двух кадров подряд и сохраняет снимок с рамкой.
- Направление «влево/вправо» определяется относительно студента, а не зеркального изображения камеры.
- Отсутствие лица и несколько лиц отмечаются в журнале.
- После запуска проверки доступен полноэкранный пробный тест с вопросами.
- Окно прокторинга и пробный тест остаются поверх остальных окон.
- В полноэкранном демо-тесте на время его открытия блокируются Alt+Tab, клавиша Windows, Ctrl+C/Ctrl+V, Ctrl+Tab, Print Screen и основные сочетания закрытия/переключения окон. Заблокированные нажатия и потеря фокуса записываются в журнал; после закрытия теста блокировка снимается.
- При обнаружении возможного смартфона сохраняется отдельный снимок кадра с рамкой детекции; снимок записывается в `reports/screenshots`, а путь к нему — в CSV-отчёт.
- Снимок можно открыть двойным щелчком по соответствующему событию в журнале.
- Кнопка **«Снимки сессии…»** показывает галерею всех снимков текущей проверки.
- На видеопотоке и снимках отображается подпись `by.horizon`.
- После завершения проверки журнал автоматически сохраняется в CSV в `reports`. У исходного кода папка находится рядом с `main.py`; у переносимой сборки — `%LOCALAPPDATA%\QostanaiProctor\reports`. Кнопку **«Сохранить копию отчёта…»** можно использовать и во время проверки.
- Кнопка **«Экспорт отчёта и снимков…»** создаёт ZIP с CSV и снимками, чтобы отправить материалы одним файлом. Архив по умолчанию сохраняется в `reports` и не загружается в GitHub.
- Кнопка завершения и закрытие окна освобождают камеру.

## Ограничения

Оценка взгляда приблизительная: калибровка снижает чувствительность к естественным небольшим движениям, но не заменяет специализированный трекер глаз. Обнаружение телефона зависит от видимой части: полностью закрытый рукой телефон камера распознать не сможет. Детектор может ошибаться: снимок показывает кадр и результат модели, но не доказывает нарушение. Подъём телефона — эвристический сигнал по его перемещению и положению; система не распознаёт направление камеры телефона и не может подтвердить, что человек фотографирует экран. Видео не записывается; изображения сохраняются только при срабатывании детектора телефона. Блокировка клавиш действует только пока открыт демо-тест; Ctrl+Alt+Del и другие системные способы выхода Windows остаются доступны. Переключение через мышь или системное меню может сработать, но потеря фокуса будет записана. Это локальный демонстрационный прототип, а не защищённый экзаменационный браузер; не используйте его единственным доказательством нарушения.
